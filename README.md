# Яндекс Алиса + Groq + Serper на Vercel

Готовый шаблон вебхука для навыка Яндекс Алисы. Разместите репозиторий в Vercel, добавьте ключ Groq и, если нужен поиск в интернете, ключ Serper.

## Настройка

1. Откройте https://vercel.com/dashboard и импортируйте свой GitHub-репозиторий.
2. После первого развёртывания откройте проект Vercel → **Settings → Environment Variables**.
3. Добавьте переменные окружения, выбрав **Production**:
   - **GROQ_API_KEY** — API-ключ из Groq Console.
   - **SERPER_API_KEY** — ключ Serper (необязательно, включает поиск в интернете).
   - **GROQ_MODEL** — необязательно. По умолчанию используется **openai/gpt-oss-20b**. Укажите точное имя другой модели, доступной вашему аккаунту Groq, если хотите её использовать.
4. После сохранения переменных откройте **Deployments** и выполните **Redeploy** последнего Production-развёртывания. Дождитесь статуса **Ready**.
5. В Vercel откройте **Settings → Domains**, скопируйте домен и добавьте в конец /api. Например: https://YOUR-PROJECT.vercel.app/api.
6. В Яндекс Диалогах откройте навык и вставьте этот полный адрес в поле **Webhook URL**.
7. Включите опцию **Использовать хранилище данных в навыке**, чтобы сохранять контекст между репликами.

Названия разделов Vercel и Яндекс Диалогов могут немного отличаться. Используйте только собственный домен проекта.

## Переменные окружения

- **GROQ_API_KEY** обязателен для ответов нейросети.
- **SERPER_API_KEY** необязателен. Если его нет, обычные ответы Groq продолжают работать, но поиск недоступен.
- **GROQ_MODEL** необязателен. По умолчанию: **openai/gpt-oss-20b**.

Ключи вводятся только в **Vercel → Settings → Environment Variables**. Не размещайте их в исходном коде, GitHub, README, Яндекс Диалогах или сообщениях. Если ключ попал в открытый доступ, отзовите его и создайте новый.

## Проверка навыка

1. Убедитесь, что в Яндекс Диалогах указан ваш адрес Vercel, заканчивающийся на /api.
2. Откройте раздел **Тестирование** в консоли Яндекс Диалогов и задайте навыку обычный вопрос.
3. Проверьте, что навык отвечает. Для проверки истории задайте второй вопрос по теме первого.

Для голосового запуска навык должен быть доступен для тестирования, а колонка или приложение Алисы должны использовать тот же аккаунт Яндекса.

## Если навык не отвечает

1. Проверьте названия **GROQ_API_KEY** и **SERPER_API_KEY**, если используете поиск, и убедитесь, что для них выбрано окружение **Production**.
2. После изменения переменных выполните **Redeploy** и дождитесь статуса **Ready**.
3. Проверьте правильность **Webhook URL**: домен должен принадлежать вашему проекту, путь должен заканчиваться на /api.
4. Откройте последнее развёртывание в Vercel и проверьте логи. Не публикуйте API-ключи и удаляйте секретные данные из логов перед отправкой кому-либо.

## Ограничение времени ответа

Яндекс Диалоги ожидают ответ от навыка около 4,5 секунды. Поэтому веб-поиск и генерация ограничены по времени. Если сервис отвечает слишком медленно, навык вернёт короткое сообщение с просьбой повторить запрос.
